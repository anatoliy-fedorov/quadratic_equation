Для запуска программы нужна установленная библиотека TXLib, скачивать с https://sourceforge.net/projects/txlib/files/latest/download.

Компиляция и запуск осуществляются с помощью e.bat (название придумано не мной).

К программе могла бы прилагаться онлайн документация, но её нет, а потому документация большинства функций прописана прямо в файлах .cpp.

Программа, как можно догадаться по названию, написана для решения квадратных(и линейных) уравнений. При запуске пользователю сразу же предлагается изменить цвет терминала
в котором будет происходить всё взаимодействие с программой. Выбор цвета предлагается только один раз, выбор осуществляется посредством ввода в терминал числа от 0 до 5 включительно,
каждое число - интерпретация одного из предложенных цветов(или цвет по умолчанию).

После выбора цвета пользователю предлагается выбрать то, как именно он хочет задать квадратное уравнение. Выбор осуществляется вводом числа от 1 до 3 включительно, 
каждое число - один из вариантов ввода.
1 - ввод только коэффициентов уравнения, записанных через пробел. Коэффициенты - действительные числа. При вводе чего-то, что не может интерпретироваться как 3 числа, программа пишет о некорректности ввода и завершается.
2 - ввод всего уравнения целиком в ввиде "a1x^2 + a2x^2 + a3x^2 ... + b1x + b2x + b3x ... + c1 + c2 + c3 ... = 0", можно менять местами любые коэффициенты a b c, переносить их через знак = 
и творить другие непотребства, на которые не хватает фантазии автора. В любом случае, если ввод будет некорректным, программа скажет об этом и завершится.
3 - ввод коэффициентов, записанных через пробел в файле input.txt, мне наверное не стоит говорить, что если с вводом что-то не так, то вы отправитесь нахуй
хотя вообще есть способ при таком вводе остановить программу навечно, она при этом не поймёт ошибки и не завершится.

После ввода коэффициентов и нажатии Enter будут посчитанны корни уравнения, но это было бы слишком просто хах, потому что я целый день ебался над дополнительной фишкой,
а именно построением графика(да, дерьмового, но хоть какого-то). Для этого и нужен TXLib, хотя он и для поддержки русского языка нужен. 

Ну так вот, после ввода коэффициентов тебе в ебало откроется окошко, в котором будут написаны корни уравнения, и нарисуется (нихуя себе) график этого уравнения.
График будет хуёвым, потому что коэффициент увеличения оси x (COEFFICIENT_X), находится в файле print_parabola.cpp и меняется ТОЛЬКО ВРУЧНУЮ, НИКАКОГО АВТОМАТА, МАТЬ ТВОЮ, ТОЛЬКО МЕХАНИКА.
